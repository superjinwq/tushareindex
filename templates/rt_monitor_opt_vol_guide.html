卖方读盘

四量

  • IV：期权现在给未来波动开的价。右侧「最新」是近 ATM 代表 IV；T 型是逐档 Black-76。
  • HV：标的刚走完的已实现。窗口 n=clip(round(DTE×252/365),5,120)，收盘对数收益 ×√252。当月 DTE<10 淡化，以下月为准。
  • 溢：中轴 IV − HV（百分点）。正=报价高于刚实现；负=刚爆完、报价已往回修。负值不是自动买权。不是 T 表期权 Δ。
  • VRP：点右侧「最新」弹窗那一行。IV 减随后 RV 的历史中位 / 均值 / 胜率。当日格子没有随后 RV。
  • 斜：认沽最新 − 认购最新（pp）。中轴均值会抹平这一边。正=认沽更贵；+0.5~+2.5 常见溢价；≥+2.5 偏肥尾，卖 put 降档；负=认购更贵。

交叉（IV Per × HV Per × 溢）

下面的「IV Per」默认取 Per 1y（与 HV Per 同为窗口分位，口径可比）；Per C / Per A 用来确认当前处在哪个波动 regime。

  1. 双高 + 溢≈0：regime 高，别因分位高就卖。
  2. IV Per 高 + HV Per 低 + 溢>0：真贵。50 / 300 更站得住。
  3. IV Per 中低 + HV Per 很高 + 溢大负：刚爆完在修，不要因为溢很负去买波动。
  4. 双低 + 溢小幅正：50 的舒适收租区；588000 仓位不能按 50 套。

IV 对回看 HV 粘、对随后 RV 松。用交叉定「贵不贵」，用弹窗 VRP 复盘，不开仓。

T 型三列分位 Per 1y / C / A

  • 三列都是中间秩百分位，只差取样窗口；一位小数 0–100 如 72.4。已取消 Rank（min–max 位置被单个极端日绑架，同一天常与分位背离）。
  • Per 1y=近 252 交易日。Per C=自配置锚点日起（波动率中枢跃升后的新常态；未配锚点的标的为 —）。Per A=全样本。
  • 比的都是同期限代表 IV，不是这张合约自己的历史。任一窗口样本不足 60 日为 —；锚点与样本量见单元格 title。
  • 只在 |Δ|∈[0.10, 0.90] 显示；仅极端翼部的反解噪声会隐藏。
  • 着色：≥70 偏贵（卖权环境）、50–70 中性偏贵、30–50 偏低、<30 便宜。三列同一套阈值。
  • 三列要一起读：A 高而 1y 低 = 拉长看仍在高波动段、但近一年已回落，不是便宜；1y 高而 C 低 = 只是近一年的高点，放到新常态里还不算贵。
  • 分位高只说明「相对自己历史贵」，还要对照右侧 溢 / HV Per / 弹窗 VRP，避免高波动段把「贵」读成可卖。
  • 右侧 IV 看板与本表同一套算法同一精度（此前 IVR 走 252 日窗、看板 Per 走全样本，同一天两处数字不一致，已统一）。
  • 义务仓优选里三列不标星：远月分位系统性偏高，四期限里的「最高」几乎恒为下季。☆ 只表示该档时年化最高。跨期限贵不贵请直接比三列数值。

本页三条路径，别混

  • Sell Put（仅 588000 / 510500 / 159915）：系统信号 + 次月钟 + 合槽。这是卖方主路径，不是看分位高就手点。
  • 垂直价差：借记方向单，吃方向 + 期限 + 微笑，不收 VRP。铁律在下方：方向、1 档、成本 0.3–0.4、止盈 2.0×、成本>0.5 剔除。588000 方向错惩罚最重，只在强信号时做。
  • T 型手扫：先右侧下月定贵便宜，再在 |Δ| 0.10–0.90 且分位有数的档位里用权利金% / 时年化 / 折溢% / 有效价选腿。

T 型卖方扫表

  • 权利金%：Call=C/(S−C) 备兑静态；Put=C/(K−C) 净接货。越高越醒目，不等于越好卖。
  • 时年化：(时值/K)×365/DTE。时值≤0 为 —。深实值负时值不要当高收益卖。
  • 有效价：Put=K−权利金（接货）；Call=K+权利金（备兑到位）。这是被指派后的账。
  • 折溢%：正=卖方有利（青绿），负=不利。近零可忽略。
  • Δ：Black-76 现货 Δ。实务卖权常瞄 |Δ| 0.20–0.35；三列分位的展示范围为 0.10–0.90。|Δ| 越高越容易被指派。
  • 最新：当日有成交=QMT 最新/量/仓；无成交=昨收、成交 0。灰字不是盘口中价。
  • 量 / 仓：已标 top3。≥1 万显示 x.x万（悬停仍是整数）。手扫至少避开空仓空量档。
  • 期限：T 型表上方。第一行是当月中轴 − 下月中轴（浅/中度/陡；|差|≤0.5pp 为平坦）和溢仍为正的期限。第二行数字是中性色，判词加粗，用法是色块（灰=不做，橙=收着做，蓝框=可以看）。认购/认沽近一年分位差 ≥8 且结论不同时分开写，卖认沽看「沽」。曲线和芯片同一道 ±1pp 才称溢为正或负。权利仓可看要溢≤−3 且 HV 分位<50。
  • 1σ：各到期段头。平值跨式和上下两档宽跨齐全时用 0.6/0.3/0.1；否则用现价×平值 IV×√(自然日/365)。行权价列底边在带内，左右边界加左边条。
