# 510050 独立 OI Wall 实施计划

## Outcome

交付可直接启动的独立 Flask 页面，在最新共同交易日上展示 510050 最近四期限的标准合约 Call/Put OI Wall、Top 3 集中度、墙位距现货、调整合约和数据质量，并以可展开步骤解释计算过程。

## Task 1：测试先行并实现纯计算核心

- **Files:** `tests/test_opt_wall_510050.py`, `opt_wall_510050.py`
- **Action:**
  - 先编写纯函数合同测试，覆盖按期限/方向/行权价聚合、并列墙位、Top 3、距离方向、0 与空 OI、标准/调整合约分离、最近四期限。
  - 运行测试并确认因缺少实现而失败。
  - 实现数值规范化、合约分类和 `buildOiWallSnapshot`，不访问 Flask 或数据库。
- **Verify:** `python -m pytest tests/test_opt_wall_510050.py -q`。
- **Done:** 纯计算测试通过，错误口径能够被测试捕获。

## Task 2：实现同日只读查询和独立 HTTP 接口

- **Files:** `opt_wall_510050.py`, `tests/test_opt_wall_510050.py`
- **Action:**
  - 使用 `DB_CONFIG_TUSHARE` 参数化查询最新共同数据日、同日 `close_qfq`、有效合约和 `opt_daily` OI。
  - 暴露 `/`、`/api/oi-wall`、`/health`；数据库与数据质量异常返回结构化错误且不泄露凭据。
  - Flask 测试使用注入/替身验证接口，不依赖写库。
- **Verify:** 聚焦 pytest；对本地 MySQL 执行有界只读探测，核对数据日、四期限与墙位。
- **Done:** API 可从真实库返回同日快照，数据库未发生写操作。

## Task 3：实现教学页面并验证运行态

- **Files:** `templates/opt_wall_510050.html`, `opt_wall_510050.py`, `tests/test_opt_wall_510050.py`
- **Action:**
  - 创建独立研究终端页面：页头、期限切换、左右 OI 柱、中轴行权价、现货标记、墙位/Top 3、计算过程、解释边界、质量区和空态。
  - 原生 CSS/JavaScript，无新增依赖；前端只读取 `/api/oi-wall`。
  - 启动独立服务并在浏览器核对实际 DOM、计算展开和 API 一致性。
- **Verify:**
  - `python -m pytest tests/test_opt_wall_510050.py -q`
  - `python -X utf8 scripts/selfcheck_delivery.py`
  - `python -m pytest tests/ -q`
  - `python -X utf8 scripts/audit_scratch_retention.py --sweep`
  - 运行态 `/health`、`/api/oi-wall` 和页面浏览器检查。
- **Done:** 页面在独立端口可访问，真实数据与公式追溯一致；交付说明列出全部验证和未验证项。

## Recovery

本阶段只新增三个业务/测试文件，无数据库迁移。回滚只需停止独立进程并撤销新增文件；现有 5000 端口服务和 T 型板不受影响。
